# 01. 요구사항 명세서 (Software Requirements Specification, SRS)

> **문서 버전**: 1.0.0  
> **표준 준거**: ISO/IEC/IEEE 29148 및 IEEE 830 기반  
> **프로젝트명**: Bisue Blog Static (웹진형 정적 마크다운 블로그)  
> **목적**: GitHub Pages에 배포되는 웹진(Webzine) 스타일의 정적 블로그 사이트 구축을 위한 기능적·비기능적 요구사항과 인수 조건(Acceptance Criteria)을 명확히 정의한다.

---

## 1. 개요 (Introduction)

### 1.1 시스템 목적
본 시스템은 로컬 레포지토리의 특정 디렉토리(`src/content/posts/`) 내에 저장된 마크다운(`.md`) 파일들을 빌드 타임에 파싱하여, **웹진(매거진) 형태의 정적 웹사이트(HTML/CSS/JS)**로 생성 및 GitHub Pages에 자동 배포하는 정적 콘텐츠 퍼블리싱 플랫폼이다.

### 1.2 범위 (Scope)
- **인풋(Input)**: 카테고리별 하위 폴더에 위치한 마크다운(`.md`) 문서 및 이미지 에셋, 사이트/카테고리 설정 파일(`src/config/`).
- **처리(Processing)**: Astro 기반 정적 사이트 생성(SSG), 마크다운 확장 문법(GFM, 코드 하이라이팅, Mermaid 다이어그램, 원시 HTML) 변환, 썸네일 및 본문 요약문(Excerpt) 자동 추출, 카테고리별 라우팅 및 페이지네이션 생성, Pagefind 정적 검색 인덱스 생성.
- **아웃풋(Output)**: GitHub Pages 서브 경로(`/bisue-blog-static/`) 호환 정적 빌드 산출물(`dist/`) 및 GitHub Actions 자동 배포 파이프라인.

### 1.3 용어 정의 (Definitions & Acronyms)
| 용어 | 설명 |
| :--- | :--- |
| **SSG (Static Site Generation)** | 빌드 시점에 마크다운 데이터를 읽어 완성된 HTML 파일들을 사전 생성하는 방식 |
| **Frontmatter** | 마크다운 파일 최상단에 `---`로 구분하여 작성하는 YAML 형식의 메타데이터 블록 |
| **Slug (슬러그)** | URL 경로의 일부로 사용되는 식별 문자열 (파일명 또는 폴더명 기반) |
| **Excerpt (요약문/미리보기)** | 목록 카드에 노출되는 본문 텍스트의 일부(평문 기준 최대 120자) |
| **TOC (Table of Contents)** | 게시글 본문의 제목 태그(`h2`, `h3`)를 추출하여 자동 생성한 문서 목차 |
| **GFM** | GitHub Flavored Markdown (표, 취소선, 체크리스트, 각주, 자동 링크 등을 지원하는 확장 규격) |
| **Base Path** | GitHub Pages 프로젝트 사이트 배포 시 도메인 뒤에 붙는 기본 서브 경로 (예: `/bisue-blog-static`) |

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 콘텐츠 로드 및 카테고리 관리 (`FR-CNT`)

| 요구사항 ID | 요구사항 명 | 상세 명세 및 인수 조건 (Acceptance Criteria) |
| :--- | :--- | :--- |
| **FR-CNT-01** | 폴더 기반 마크다운 로드 | - `src/content/posts/<category>/<slug>.md` 경로의 모든 `.md` 파일을 빌드 시점에 스캔하여 로드한다.<br>- 하위 폴더 구조는 **1단계 단일 카테고리**(`posts/<카테고리폴더>/<파일>.md`)를 기준으로 한다. |
| **FR-CNT-02** | 카테고리 자동 인식 및 메타 매핑 | - `src/content/posts/` 직속 하위 폴더명을 카테고리 `slug`로 자동 인식한다.<br>- `src/config/categories.ts` 설정 파일에 해당 폴더명의 한글 표시명(`label`), 설명(`description`), 노출 순서(`order`)를 선택적으로 정의할 수 있다.<br>- 설정 파일에 등록되지 않은 신규 폴더가 존재하더라도 에러 없이 폴더명을 그대로 표시명으로 사용하여 메뉴에 자동 노출(등록된 카테고리 뒤 가나다/알파벳순 정렬)해야 한다. |
| **FR-CNT-03** | 초안(Draft) 필터링 | - Frontmatter에 `draft: true`가 설정된 게시글은 프로덕션 빌드(`npm run build`) 시 목록, 상세 페이지, 검색 인덱스에서 제외한다. (개발 서버 `npm run dev`에서는 확인 가능) |
| **FR-CNT-04** | 썸네일 결정 및 Fallback | 게시글의 대표 썸네일 이미지는 다음 우선순위로 결정한다:<br>1. **1순위**: Frontmatter의 `thumbnail` 필드에 지정된 이미지 경로(상대 경로, `public/` 경로, 외부 URL 모두 지원)<br>2. **2순위**: Frontmatter에 미지정 시, 마크다운 본문 내 첫 번째 이미지 문법(`![alt](src)` 또는 `<img src="...">`)의 경로를 자동 추출<br>3. **3순위**: 본문에도 이미지가 없을 경우, 기본 플레이스홀더 이미지(`/images/default-thumbnail.svg`)를 적용 |
| **FR-CNT-05** | 본문 미리보기(Excerpt) 추출 | 목록 화면 카드에 표시할 본문 텍스트 미리보기는 다음 규칙으로 생성한다:<br>1. **1순위**: Frontmatter에 `description` 값이 존재하면 이를 우선 사용한다.<br>2. **2순위**: 미지정 시 마크다운 본문에서 코드 블록, Mermaid 블록, HTML 태그, 이미지, 마크다운 기호(`#`, `*`, `>`, `[...](...)` 등)를 제거한 순수 평문(Plain Text)을 추출한다.<br>3. 추출된 평문이 **120자**를 초과하면 120자까지 자른 후 말줄임표(`...`)를 부착한다. |

### 3.2 마크다운 문법 지원 (`FR-MD`)

| 요구사항 ID | 요구사항 명 | 상세 명세 및 인수 조건 (Acceptance Criteria) |
| :--- | :--- | :--- |
| **FR-MD-01** | 표준 CommonMark 및 GFM 지원 | - 제목(`h1`~`h6`), 문단, 강조(`bold`, `italic`), 인용문(`blockquote`), 순서 있는/없는 목록, 수평선, 링크, 이미지를 완벽 지원한다.<br>- `remark-gfm` 라이브러리를 통해 **표(Table)**, **취소선(`~~`)**, **체크리스트(`- [x]`)**, **각주(`[^1]`)**, **자동 URL 링크**를 지원한다. |
| **FR-MD-02** | 코드 블록 문법 강조 및 부가 UI | - 검증된 오픈소스 라이브러리(`astro-expressive-code`)를 사용하여 다중 프로그래밍 언어 문법 강조(Syntax Highlighting), **클립보드 복사 버튼**, 파일명/타이틀 헤더 표시를 지원한다.<br>- 직접 파서를 구현하지 않고 라이브러리 설정 조합만으로 동작해야 한다. |
| **FR-MD-03** | 다이어그램 렌더링 (Mermaid) | - 마크다운 내 ```` ```mermaid ```` 코드 블록 작성 시, 공식 `mermaid` 라이브러리를 활용하여 플로우차트, 시퀀스 다이어그램 등을 SVG 다이어그램으로 변환 렌더링한다. |
| **FR-MD-04** | 원시 HTML 태그 허용 | - `rehype-raw` 플러그인을 통해 마크다운 내부에 작성된 원시 HTML 태그(`<iframe>`, `<details>`, `<summary>`, `<kbd>`, `<mark>`, `<video>`, `<div>`, `<span>` 등)가 이스케이프되지 않고 정상 렌더링되어야 한다. |
| **FR-MD-05** | 콜아웃/인용 알림 블록 | - `remark-github-blockquote-alert` 라이브러리를 사용하여 GitHub 스타일 알림 블록(`> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!CAUTION]`)을 스타일링된 박스로 렌더링한다. |
| **FR-MD-06** | 다중 이미지 참조 방식 지원 | - 마크다운 본문 및 Frontmatter 썸네일에서 **상대 경로**(`./img.png`), **`public/` 기준 절대 경로**(`/images/img.png`), **외부 URL**(`https://...`) 3가지 방식을 모두 지원한다. |

### 3.3 네비게이션 및 레이아웃 (`FR-NAV`)

| 요구사항 ID | 요구사항 명 | 상세 명세 및 인수 조건 (Acceptance Criteria) |
| :--- | :--- | :--- |
| **FR-NAV-01** | 상단 헤더 및 카테고리 메뉴 | - 사이트 최상단 고정(Sticky) 헤더에 **사이트 로고(홈 링크)**, **전체 글 메뉴**, **카테고리 목록 메뉴**, **검색 버튼**을 배치한다.<br>- 각 카테고리 항목 옆 또는 툴팁/배지로 해당 카테고리의 게시글 수를 확인하거나 클릭 시 `/category/<category-slug>/` 페이지로 즉시 이동한다.<br>- 현재 보고 있는 카테고리(또는 상세 글이 속한 카테고리)는 메뉴에서 활성(Active) 상태로 강조 표시한다. |
| **FR-NAV-02** | 모바일 반응형 드로어 메뉴 | - 모바일/태블릿 작은 화면(`md` 브레이크포인트 미만)에서는 상단 헤더 우측의 햄버거 버튼을 클릭하면 슬라이드/드로어 메뉴가 열리며 전체 카테고리 목록을 확인·이동할 수 있어야 한다. |

### 3.4 페이지별 화면 기능 (`FR-PAGE`)

| 요구사항 ID | 요구사항 명 | 상세 명세 및 인수 조건 (Acceptance Criteria) |
| :--- | :--- | :--- |
| **FR-PAGE-01** | 매거진 큐레이션 홈 화면 (`/`) | - 첫 화면은 **카테고리별로 섹션을 구분**하여 각 카테고리의 최신 게시글을 **최대 3개**(데스크톱 3열 1줄, 설정에서 3~4개 변경 가능)씩 보여주는 웹진 큐레이션 레이아웃으로 구성한다.<br>- 각 카테고리 섹션 상단에는 **카테고리 이름**, **카테고리 설명(있을 경우)**, 우측에 **'더보기 (전체 N개 글 보기 →)'** 링크를 배치하여 클릭 시 해당 카테고리 목록 페이지로 이동시킨다. |
| **FR-PAGE-02** | 카테고리별 게시글 목록 화면 (`/category/<category>/[...page]`) | - 선택한 카테고리의 헤더(카테고리명, 설명, 총 게시글 수)와 게시글 카드 목록을 표시한다.<br>- 카드는 **데스크톱 3열 / 태블릿 2열 / 모바일 1열 그리드**로 배치되며, **페이지당 9개**의 게시글을 노출한다.<br>- 각 카드는 **대표 썸네일(16:9 비율)**, **카테고리 배지**, **제목(최대 2줄 말줄임)**, **본문 미리보기(최대 120자, 3줄 말줄임)**, **작성일**을 표시한다.<br>- 하단에는 페이지 번호 네비게이션(이전, 1, 2, 3..., 다음)을 표시한다. |
| **FR-PAGE-03** | 전체 게시글 목록 화면 (`/posts/[...page]`) | - 카테고리 구분 없이 전체 게시글을 최신순으로 모아 볼 수 있는 목록 페이지도 동일한 3열 카드 그리드 + 페이지당 9개 페이지네이션 형태로 제공한다. |
| **FR-PAGE-04** | 게시글 상세 화면 (`/posts/<category>/<slug>/`) | - **상단 헤더 영역**: 카테고리 배지(클릭 시 해당 카테고리 목록으로 이동), 게시글 제목(`h1`), 작성일(`YYYY. MM. DD.`), 대표 썸네일(선택적 표시 가능)을 렌더링한다.<br>- **본문 영역**: 변환된 마크다운 본문을 웹진 에디토리얼 타이포그래피 스타일로 렌더링한다.<br>- **목차(TOC) 영역**: 본문 내 `h2`, `h3` 헤딩을 추출하여 데스크톱(`xl` 이상)에서는 우측 Sticky 사이드바로, 모바일/태블릿에서는 본문 상단 접이식(`<details>`) 박스로 표시한다.<br>- **하단 네비게이션**: **같은 카테고리 내** 작성일 기준 **이전 글(Prev)** 및 **다음 글(Next)** 카드 링크와 '목록으로 돌아가기' 버튼을 제공한다. |
| **FR-PAGE-05** | 정적 키워드 검색 기능 | - 빌드 시점에 `pagefind`를 통해 정적 검색 인덱스를 생성한다.<br>- 상단 헤더의 검색 버튼 클릭 시 검색 모달(다이얼로그)이 열리고, 한글/영문 키워드 입력 시 제목과 본문 내용이 일치하는 게시글 목록과 하이라이트된 스니펫을 즉시 보여준다. |

## 4. 비기능 요구사항 (Non-Functional Requirements)

| 분류 | 요구사항 ID | 상세 내용 |
